Lineas de comando 🧩 Alias táctiles para Git Bash + Notepad++
xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# Alias principal para abrir Notepad++
alias np='"/c/Program Files/Notepad++/notepad++.exe"'

# Alias para abrir archivos clave del sitio
alias npindex='np index.html'
alias npstyle='np style_nuevo.css'
alias nppampa='np pampa.html'
alias nppiccolo='np piccolo_punzone.html'
alias npguri='np guri_2012.html'

# Alias para abrir scripts quirúrgicos
alias npsubir='np "script automatico subir sitio.txt"'
alias npmigrar='np migrar_a_raiz.sh'
alias npbash='np "codigo de bash.txt"'
alias nprenombrar='np "script automatico renobrar sitio y carpetas.txt"'

# Alias para abrir todos los .html clave juntos (requiere que Notepad++ esté configurado para múltiples pestañas)
alias npall='np index.html && np pampa.html && np piccolo_punzone.html && np guri_2012.html && np style_nuevo.css'


✅ Activación
Pegá este bloque al final de tu ~/.bashrc:

bash
nano ~/.bashrc
Guardá y salí (Ctrl + O, Enter, Ctrl + X)

Recargá:

bash
source ~/.bashrc
Ahora podés usar comandos como:

bash
npindex        # Abre index.html
npstyle        # Abre style_nuevo.css
npsubir        # Abre el script de subida
npall          # Abre todo junto

🧩 Función Bash: subirlegado
bash
subirlegado() {
  echo -n "📝 Mensaje de commit: "
  read mensaje
  git add .
  git commit -m "$mensaje"
  git push origin main && cmd //c start https://escmilm-sketch.github.io/Legado
}

Integrasion de Notepad++ a Bash

Perfecto, Claudio. Esta es la línea quirúrgica que podés copiar a tus apuntes para integrar Notepad++ como alias en Git Bash:

bash
alias np='"/c/Program Files/Notepad++/notepad++.exe"'
📌 Esta línea debe ir al final de tu archivo ~/.bashrc. Luego ejecutás:

bash
source ~/.bashrc
Y ya podés usar el comando:

bash
np archivo.html
Por ejemplo:

bash
np style_nuevo.css
np index.html
np "script automatico subir sitio.txt"
